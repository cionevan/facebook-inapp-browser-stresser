# Dazzling Salk – Browser & Social Media Traffic Stresser

Modern web uygulamaları, Facebook reklam yönlendirmeleri ve yüksek ölçekli trafik senaryoları için geliştirilmiş gerçek Chromium tabanlı stress test aracı.

## 🚀 Hızlı Başlangıç

Detaylı kullanım, mimari ve ayarlar için [stresser/README.md](stresser/README.md) dosyasını inceleyin.

```bash
cd stresser
pip install -r requirements.txt
playwright install chromium
python main.py
```
